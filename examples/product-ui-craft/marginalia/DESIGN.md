# Marginalia

A reader asks questions about a small data file and checks the answer against the source. The first screen shows their question, a short answer, an hourly chart and a composer ready for a follow-up. Earlier conversations live in a quiet side rail.

Use a white reading surface, a cool paper rail `#f5f6f9`, ink `#24262d`, secondary ink `#5d616d`, fine rules `#e0e2e9` and indigo `#5556a7` for the folded-page mark and the weekday series. The weekend series uses burnt orange `#ad5f36`, dashes and a different point symbol. Keep a single system-sans family, tabular numerals and a 740px reading column. The chart gets a scale, unit and legend. Its source opens to the actual rows.

Use 4/8/12/16/24/32/48px spacing, 32/36/40px desktop controls, 44px mobile navigation and a 52px file attachment with two lines of text. Use 8px corners on controls and 15–20px on the chart, user bubble and composer. Supporting text is 12–14px, messages 16px and the main finding 23–30px. A white surface and a single subtle shadow distinguish the floating composer. The desktop rail becomes a native drawer dialog on phones. Keep motion under 180ms and respect reduced motion and keyboard focus.

The chats and attendance data are fictional. The initial answer, chart, CSV download and follow-ups use the same embedded hourly averages. This standalone demo answers local questions about those values. It has no server or model connection.
